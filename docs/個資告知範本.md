# 校園巡邏系統 個人資料蒐集告知暨同意書（範本）

> 本範本供總務處參考，正式使用前請由學校個資保護窗口或法務單位審閱。【建議查證】

元智大學（以下稱本校）依《個人資料保護法》第 8 條規定，向您告知下列事項：

**一、蒐集目的**
校園安全巡查管理、安全事件處理、保全勤務稽核。

**二、蒐集之個人資料類別**
1. 識別資料：姓名、工號、使用之手機裝置代碼。
2. 位置資料：巡邏期間之 GPS 定位與巡邏軌跡。
3. 影像資料：巡查現場照片、身分確認自拍照。
4. 生物特徵：開始巡邏時以手機內建指紋或臉部辨識解鎖。本校僅取得「驗證是否通過」之結果，不取得、不儲存您的指紋或臉部特徵。

**三、蒐集期間**
僅於您在系統按下「開始巡邏」至「結束巡邏」期間蒐集位置資料，非巡邏時間不蒐集。

**四、利用期間、地區、對象及方式**
1. 期間：巡查照片與自拍照保存 180 天後刪除；巡查文字紀錄保存＿＿年。
2. 地區：本校及本校委託之雲端服務所在地。
3. 對象：本校總務處、保全主管、校安中心；發生安全事件時，得提供予司法或治安機關。
4. 方式：以電子方式處理、查詢與統計。

**五、您的權利**
您得向總務處申請查詢、閱覽、複製、補充、更正本人資料，或請求停止蒐集、處理、利用及刪除。

**六、不提供之影響**
您得自由選擇是否提供。若不提供位置與照片資料，將無法使用本系統執行巡邏勤務，本校將另行安排紙本巡邏或其他方式。
